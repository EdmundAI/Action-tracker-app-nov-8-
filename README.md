# Action Tracker

A single page meeting action tracker. Add actions with an owner and due date, group them by owner, tick them off, and see open, done and overdue counts. Data is saved in the browser's local storage.

## Deploy on Vercel

1. Import this repository at vercel.com/new.
2. Framework Preset: Other. Leave the build command and output directory empty.
3. Click Deploy.

No build step is needed. `index.html` is served as is.
